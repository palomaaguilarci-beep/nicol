# Programas en Turbo Pascal

Este repositorio contiene tres ejemplos compatibles con Turbo Pascal:

- `hola_mundo.pas`: muestra un mensaje de **Hola Mundo**.
- `calculadora.pas`: solicita al usuario dos números reales y calcula la suma, resta, multiplicación y división.
- `operaciones_procedures.pas`: solicita dos números y realiza las cuatro operaciones utilizando varios `procedure`.

## Programa con varios procedimientos

`operaciones_procedures.pas` organiza la funcionalidad mediante estos `procedure`:

- `PedirNumeros`
- `MostrarSuma`
- `MostrarResta`
- `MostrarMultiplicacion`
- `MostrarDivision`
- `MostrarResultados`

El programa evita la división entre cero y muestra los resultados con dos decimales.

## Calculadora con procedimientos

`calculadora.pas` también utiliza varios procedimientos, incluyendo `MostrarSaludo`, `LeerNumero` y los procedimientos de cada operación aritmética.

## Ejecución en Turbo Pascal

1. Abre `hola_mundo.pas`, `calculadora.pas` u `operaciones_procedures.pas` en Turbo Pascal.
2. Compila con `Alt+F9`.
3. Ejecuta con `Ctrl+F9`.

Los programas aceptan números enteros o decimales usando el formato decimal configurado por Turbo Pascal.
